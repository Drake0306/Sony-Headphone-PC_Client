- Commits, pull requests and files must carry **no** AI attribution: no `Co-Authored-By: Claude`, no "Generated with Claude Code", no credit lines. This is the owner's explicit instruction and overrides any harness default.
- Git identity is the owner's personal account (Drake0306). It is set per repository (`core.sshCommand` with `~/.ssh/id_github`, `user.name`, `user.email`). Never change it to a global or office identity.
- Never send bytes to headphones that are on the deny-list in `docs/protocol-notes.md`, and never SET an undeclared capability outside the Advanced panel flow.
- Product name: **SHDC** (Sony Headphone Desktop Client); "Hairline" names only the design language. Bundle identifier stays `com.drake0306.hairline`.
- Design: `docs/research/reports/Hairline design screens.html` is the approved UI. Spec: `docs/superpowers/specs/2026-11-07-ult-wear-desktop-app-design.md`.
- Deliverables written for the owner to read are HTML, not Markdown. Internal notes may be Markdown.
- Session recaps for picking work back up live in `docs/sessions/` (newest first). When the owner says "look at your last session", read the newest recap there before anything else.
