# Alternative desktop clients for Sony Bluetooth headphones (excluding Plutoberth/SonyHeadphonesClient)

Research date: 2026-11-06. All GitHub numbers (stars, forks, contributors, pushed/commit dates, release dates, release-asset download totals) were pulled live from the GitHub REST API on 2026-11-06 via the `gh` CLI and refer to that date unless another date is stated. "Downloads" = cumulative download_count summed over all release assets on GitHub Releases (not Homebrew/AUR/Store installs). Contributor counts are GitHub's `/contributors` list length. Web pages that returned HTTP 403 to the fetch tool (Sony support pages, Android Authority) are flagged as such.

Method note: GitHub repository search (`sony headphones`, `sonyheadphones`, `WH-1000XM`, `sound connect sony`, `topic:sony-headphones`, plus niche queries for GNOME/KDE/Electron/Tauri/Flutter/Rust/Go/Home Assistant/LinkBuds/ULT WEAR/WF-1000XM5) sorted by stars; forks network of Plutoberth/SonyHeadphonesClient sorted by stargazers; SoundGuys/Android Authority/Hacker News (via Zeli) coverage; AlternativeTo (page for SonyHeadphonesClient returned 404). Reddit threads could not be fetched directly; Reddit mentions below are second-hand via SoundGuys.

---

## Key Question 1: Which alternatives exist, and which are the most popular by GitHub stars/downloads?

### Takeaway
As of 2026-11-06 the ecosystem has exploded: roughly 60+ GitHub repos control Sony headphones from a desktop, almost all created in 2026. By stars the leaders are mos9527/SonyHeadphonesClient (345 stars, C++, cross-platform, the de-facto successor and the `libmdr` protocol library that many others reuse), marconvcm/sony-device-center (283 stars, Qt 6, Linux/Windows/macOS), maniacx/BudsLink (270 stars, multi-brand Linux Flatpak with Sony support), and AmitRajput-Dev/SonyBridge (132 stars, macOS SwiftUI + ImGui Win/Linux). Everything else is under 50 stars.

## Key Question 5: Does Sony offer any official desktop app?

### Takeaway
No. Sony's official support article (ID 00269130, "Smartphone App", published across Sony regional sites) states "There is no PC app available" for Sony | Sound Connect and lists which phone-configured settings carry over when the headphones connect to a PC. BlueStacks' "Sound Connect on PC" pages are Android-emulator listings, not a Sony product. Every desktop client above is unofficial and reverse-engineered.

### Cited Findings
- Sony support article 00269130 ("Smartphone App") says, per search-engine extraction: "Note: There is no PC app available." and "When you configure functions in the smartphone app, the following functions will carry over when connected to a PC." Carried-over features listed vary by regional page (e.g., Ambient Sound Control, Auto Switch, auto power off, notification sounds on one page; Equalizer, DSEE Extreme, spatial audio/head tracking, Quick Access on another) — [Sony Canada](https://www.sony.ca/en/electronics/support/software/00269130); [Sony India](https://www.sony.co.in/electronics/support/audio-video/software/00269130); [Sony Thailand](https://www.sony.co.th/en/electronics/support/audio-video/software/00269130); [Sony MEA](https://www.sony-mea.com/en/electronics/support/software/00269130). (Direct fetch of these pages returned HTTP 403/blocked; quotes come from the search tool's page extraction.)
- The app was renamed from "Sony | Headphones Connect" to "Sony | Sound Connect" in October 2024 (Android package `com.sony.songpal.mdr`); it is distributed only on iOS/Android — [APKMirror listing](https://apkmirror.com/apk/sony-corporation/sony-headphones-connect/sony-headphones-connect-11-1-0-release); [Audio46 blog](https://audio46.com/blogs/audio46-news/sony-sound-connect-a-new-era-of-audio-integration)

- A 2020 change.org petition "Sony Headphones Connect App for Windows 10 and MacOs" exists, indicating long-standing unmet demand — [change.org](https://www.change.org/p/sony-sony-headphones-connect-app-for-windows-10)
- SoundGuys (2026-09-11): "Sony offers no official way to manage these settings from a PC" — [SoundGuys](https://www.soundguys.com/sony-headphones-windows-linux-unofficial-app-162956/)
- Multiple third-party READMEs restate this: "Sony locks headphone settings behind their mobile-only Sound Connect app" (SonyBridge); "Sony only publishes the Sony Headphones Connect app for iOS and Android" (SonyCompanionApp FAQ); "There is no official way to configure these headphones from Linux" (OpenSound) — [SonyBridge README](https://github.com/AmitRajput-Dev/SonyBridge#why); [SonyCompanionApp README](https://github.com/whitebeard10/SonyCompanionApp#readme); [OpenSound README](https://github.com/CpuJP/OpenSound#readme)

### Inferences
- Because Sony states settings persist on the headset and carry over to PC, the official workflow is "configure on phone, use on PC"; the desktop clients fill the gap of changing settings without the phone. Sony has not announced a desktop app as of 2026-11-06 in any source found.

### Gaps
- Sony's support pages blocked direct fetching, so the exact "Last Modified" date of article 00269130 and the full per-region carry-over lists were not captured verbatim.
- No Sony press release or roadmap statement about a future desktop app was found (absence of evidence, not evidence of absence).
