Things the reviews caught before merge

  • Once the probe marked a function "proven", the normal controls, scenes and the CLI could have sent a SET to an undeclared function. Proven now unlocks reads only; typed writes still need a declared function, as the repo rule says.
  • A hand-derived table would have recorded the wrong function as proven for ten of the probe's reads. It is now written out pair by pair against the protocol headers, with a test over every catalogue entry.
  • The frame log streamed a 50 KB snapshot up to 100 times a second while the Advanced screen was open. It is throttled to five a second.
  • In a packaged app the capture files would have landed in the wrong folder. They now go to ~/Library/Logs/com.drake0306.hairline/captures/.
  • The CLI and the app both built to a file called hairline, which caused one of my agents to kill your dev session by mistake. The CLI is now hairlinectl.
  • In the Advanced equalizer, Send is refused unless the headphones report exactly six bands of 21 steps, and the faders freeze while a send is in flight so what you see is what goes out.
